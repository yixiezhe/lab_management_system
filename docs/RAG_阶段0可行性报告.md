# LabOps Agent RAG 阶段 0 可行性报告

> 日期：2026-09-03｜状态：阶段 0 已完成｜本阶段未安装 Qdrant、未下载模型、未改业务代码或数据库

## 1. 结论

本阶段完成了五项工作：模型网关 Embedding 探测、主机资源检查、知识源盘点、25 条最小评测集，以及技术路线决策。

结论如下：

1. 当前模型网关可以列出生成模型，但没有暴露 Embedding 模型，标准 `/v1/embeddings` 返回 404，不能直接复用当前 `gpt-5.6-luna` 生成模型做向量化。
2. 主机磁盘和 CPU 足够启动小规模 Qdrant；6333/6334 端口当前未占用。
3. 当前 WSL 仅有 7.6 GiB 内存、约 3.7 GiB 可用，且没有可用于推理的 NVIDIA GPU；多个现有容器已占用约 4 GiB。BGE-M3 可能勉强在 CPU 上运行，但不适合作为当前主机的常驻首选方案。
4. 推荐第一版使用轻量本地中文 Embedding 做离线/低并发验证，或者另行申请支持 Embedding 的可信 API。BGE-M3 保留为资源扩容后的对照方案。
5. 结构化数据基础较好，但正式 SOP 资料不足。现阶段不能直接构建“全仪器知识库”，应先整理采购流程和 XRD 教程，并补齐其他仪器的正式规则/SOP。
6. 暂不启动 Qdrant。下一阶段先做轻量 Embedding 基准和文档治理，达到验收条件后再增加容器与知识表。

## 2. 模型网关探测

探测原则：沿用后端已有令牌，只发送“实验室仪器预约规则”这一条无敏感短文本；不输出令牌，不上传真实资料。

| 项目 | 结果 |
| --- | --- |
| `GET /v1/models` | HTTP 200 |
| 单次延迟 | 约 1421 ms |
| 返回模型数量 | 10 |
| 名称含 embed/bge/gte/e5 的模型 | 0 |
| `POST /v1/embeddings` | HTTP 404 |
| Embedding 探测延迟 | 约 1344 ms |
| 测试输入 | 无敏感短文本 |

说明：这些是单次连通性数据，不是性能 Benchmark。404 表明当前网关未提供标准 Embedding 路由，而不是令牌泄露或业务系统故障。

决策：

- 当前网关继续只承担生成模型调用；
- 不伪造 `/embeddings` 兼容层，也不拿生成文本代替向量；
- 若未来网关新增 Embedding，需要重新测试模型名称、维度、批处理、费用、隐私和限流。

## 7. 推荐路线

### 路线 A：轻量本地 Embedding PoC（当前推荐）

先比较 2～3 个适合 CPU 的中文/多语言小模型，不接业务流量：

- 使用首批已确认文档；
- 只构建本地临时索引；
- 测量模型冷启动、单查询 P50/P95、峰值内存、Recall@5；
- 达标后再决定是否作为正式模型；
- 不因为模型体积小就省略混合检索和引用校验。

### 路线 B：可信外部 Embedding API

只有满足以下条件才采用：

- 支持中文和批量 Embedding；
- 有明确的数据保留和训练使用政策；
- 可接受的价格、超时和速率限制；
- 能固定模型版本或记录版本变化；
- 敏感文档可留在本地，或已经完成脱敏和授权。

### BGE-M3 的位置

BGE-M3 不被否定，但当前不适合作为默认常驻服务。可在以下条件满足后作为质量对照：提高 WSL 内存上限、确认 CPU 延迟可接受，或增加可用 NVIDIA GPU；测试时必须与轻量模型使用同一评测集。

## 8. Qdrant 建议

暂不启动。Embedding PoC 和文档治理通过后再进入阶段 1：

- 固定镜像版本；
- 仅 Docker 内网暴露 6333，不映射到校园网；
- 使用命名卷与健康检查；
- 初始设置内存/CPU/日志限制；
- Collection 使用 `dense + sparse + payload indexes`；
- 先建索引、保持 `LABOPS_RAG_ENABLED=False`，评测通过后灰度；
- Qdrant 不可用时，现有采购和预约 Tools 必须继续工作。

## 9. 下一阶段准入条件

以下条件满足后才开始数据库迁移和 Qdrant 接入：

- 至少确认 1 份采购制度、1 份 XRD 教程及责任人/版本；
- 至少补齐输力强或一种高频仪器的正式规则；
- 轻量模型或外部 API 在 25 条评测集上完成 Recall@5 与延迟测试；
- 峰值内存不会挤压现有 MySQL、Guacamole 和前后端；
- 明确原文下载/预览权限；
- 确定 Qdrant 固定版本、备份和回退方案；
- 所有知识类标准答案经过人工复核。
